PDF 크롤러

PDF 시트 자동 다운로드

PDF 전용 시트 열기 ↗ · A열에 URL을 한 줄씩 입력하면 자동으로 받습니다.

이 컴퓨터에서 앱이 실행되는 동안 10초 간격으로 확인합니다. 모든 파일은 G:\내 드라이브\0\_받는함\크롤러 아래에 모입니다. 하위 폴더 기본값은 PDF이며, 완료 후 시트에 파일명·저장 경로가 표시됩니다.

http:// · https:// 주소만 추출하며, 같은 입력 안의 중복 주소는 한 번만 등록합니다. 한 번에 최대 200개입니다.

자동 처리 상태를 확인하는 중...

지금 처리는 시트에 저장된 대기 링크를 즉시 읽어 한 번 처리합니다. 자동 처리가 꺼져 있어도 사용할 수 있습니다. 시트 수정이 저장된 뒤 눌러주세요.

실패한 행은 I열의 원인을 확인하고 D열(status)을 pending으로 바꾸면 재시도합니다. 중지하면 현재 파일 처리 후 멈춥니다.

파일·설명 페이지·미러 URL 다운로드

페이지에 표시된 다운로드·미러 링크를 최대 4단계 따라갑니다. 실패한 미러는 다음 후보로 넘어갑니다. URL에 MD5가 명시되어 있거나 직접 입력하면 받은 원본과 대조합니다. PDF·EPUB·ZIP·DjVu·이미지를 지원하며, 로그인이나 JavaScript 조작이 필요한 페이지는 자동 처리하지 못할 수 있습니다.

페이지에서 링크 찾기 (Link Gopher)

페이지 안의 링크를 뽑아서 보여줍니다. 게시물 목록(목록 페이지면 글 목록 — 고른 글들에 들어가 파일을 모아옴), 파일 양식(PDF·HWP·엑셀 같은 파일만, 같은 파일은 한 줄로), 전체(모든 링크, 기존 방식), URL 포함(입력한 문구가 주소에 들어간 링크만).
