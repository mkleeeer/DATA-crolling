# 파일·미러 리졸버

`/pdf` 상단에 파일 직접 주소, 설명 페이지 또는 미러 페이지 URL을 넣습니다.
알고 있는 MD5가 있으면 선택 입력란에 32자리 16진수로 입력합니다. 성공 시
최종 파일 주소, 원본 응답의 MD5, 비교 대상과의 일치 여부를 표시합니다.
성공 메시지 또는 받은 PDF 목록의 **파일 받기**를 누르면 저장된 파일을
브라우저로 받습니다. 원격 주소에 다시 접속하지 않습니다.
MD5는 파일 대조에 쓰며 보안상 고유성이나 출처의 신뢰성을 보장하지 않습니다.

## 처리 범위

- 기존 한 단계 `.pdf` 링크 탐색을 `resolver.py`의 제한된 다단계 탐색으로 교체.
- HTML의 다운로드/미러/GET/원문 링크, `download` 속성, 문서 확장자,
  명시적 MD5 URL, meta refresh 대상 중 실제로 표시된 HTTP(S) 주소만 사용.
  상대 주소와 쿼리 문자열을 유지하고 `<base href>`도 반영.
- 최대 깊이 4, 후보 요청 총 12개, 페이지당 후보 8개. 순환 링크 차단.
  잘못된 URL이나 ed2k 등 지원하지 않는 링크는 건너뛰고, 파일/GET 링크를
  먼저 시도합니다. 사이트 공통 미러 디렉터리·언어 전환 메뉴는 제외합니다.
  HTTP 리다이렉트는 각 요청당 최대 10회이며 방문 전에 주소 검사를 수행.
- HTTP 실패, 알 수 없는 응답, 체크섬 불일치 시 다른 미러를 순서대로 시도.
  미러 후보에는 HTTP 어댑터의 자동 재시도를 적용하지 않아 같은 후보에서
  재시도가 중첩되지 않습니다. 전체 처리 시간에 대한 절대 상한은 아닙니다.
  탐색 경로와 실패 사유는 `[resolver]` 로그에 남김. 알 수 없는 응답은
  기존 512바이트 진단과 원본 임시 저장을 사용.
- 파일은 기존 PDF/EPUB/ZIP/DjVu 시그니처 또는 Pillow 이미지 디코딩으로 식별.
  명시적 `?md5=...`, `/md5/<32자리>` 또는 API `expected_md5`가 있으면
  변환 전 원본 응답 전체와 대조. 불일치한 파일은 정상 저장/DB 등록하지 않음.
  임의의 32자리 ID를 MD5로 추측하거나, MD5만으로 다운로드 주소를 만들어내지 않음.
- 사이트별 미러 호스트를 추측하거나 로그인/스크립트 폼을 실행하지 않음.
  파일 구조를 끝까지 검증하는 바이러스 검사나 PDF/EPUB 유효성 검사 기능은 아님.

## 기존 큐와 호환

PDF 화면의 Link Gopher는 기존 `/api/submissions/add`에 `kind: "file"`을
추가해 제출합니다. submissions의 기존 A:H 열은 유지하고 I열에 `kind`를
추가했습니다. 새 시트의 헤더에는 자동 포함되며, 기존 시트에서는 I1을
`kind`로 표시할 수 있습니다. 워커는 열 위치로 읽으므로 헤더 변경 전에도
동작합니다. 이전 8열 행은 빈 kind로 읽어 기존 이미지 추출 동작을 유지합니다.

file 행과 명시적 MD5 URL은 원래 URL 한 개를 images 큐에 넘겨 다운로드
워커가 리졸버를 호출하게 합니다. 책 표지를 파일 대신 큐에 넣지 않도록
파일 모드를 분리했으며, 일반 이미지 제출과 og:image 모드는 계속 지원합니다.
Google Sheets 인증은 기존과 동일하게 필요합니다. 이번 검증은 실제 시트에
접속하거나 내용을 변경하지 않았습니다.

단일/일괄 다운로드 API는 선택적으로 `expected_md5`를 받습니다.
성공 응답에 `requested_url`, `resolved_url`, `md5`, `md5_verified`가 추가됩니다.
DB에는 최종 파일 URL과 출발 페이지가 기록되며, MD5 필드는 다운로드 응답과
로그에만 제공됩니다. MD5 미지정 시 계산한 값은 보여주지만 검증 완료로 표시하지 않습니다.

검증 명령: `venv\Scripts\python.exe -m unittest discover -s tests -v`.
화면에 남아 있던 직접 다운로드 요청은 최종 CDN 연결 시간 초과로 실패했습니다.
첫 요청부터 실패하면 미러 목록을 읽을 수 없으므로 미러가 나열된 원래 설명 페이지를
입력해야 합니다. 특정 사이트의 설명/미러 페이지 구조와 실제 다운로드 성공은 아직
검증하지 못했습니다.
